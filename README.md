# DPI Application

## Overview

This project aims to develop a web application for managing Electronic Patient Records (EPRs). The application will centralize patient information, including medical history, treatments, and test results, to improve healthcare delivery and communication among healthcare providers.

## Technologies Used
* **Frontend:** Angular, TypeScript
* **Backend:** Django, Python
* **Database:** MySQL
* **API:** REST
* **Testing:** pytest, Selenium
* **Version Control:** Git
* **Collaboration:** GitHub

## Features
* **Patient Management:**
    * Create, update, and delete patient records
    * Search patients by social security number or QR code
* **Medical Records:**
    * Record medical history, diagnoses, and treatments
    * Manage prescriptions and test results
    * Generate reports and graphs
* **User Roles:**
    * Administrative staff
    * Doctors
    * Nurses
    * Pharmacists
    * Lab technicians
    * Radiologists
* **Integration:**
    * Integrate with external systems (e.g., hospital information system, pharmacy system) using REST API
